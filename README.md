# Linux Basics Command-Line Practice

Welcome to my Linux practice repository!  
This repo contains hands-on exercises covering **Linux command-line fundamentals** on Ubuntu, which are essential for DevOps and server management.

## What’s Inside
**Basic Navigation** – Explore directories and files ("pwd", "ls", "cd")
**Directory & File Management** – Create, edit, and organize files ("mkdir", "touch", "nano")
**Permissions & Ownership** – Understand and manage access ("chmod", "chown")
**System Monitoring** – Check disk, memory, and running processes ("df", "free", "top")
**Package Management** – Install and remove software ("apt update", "apt install", "apt remove")
**Command Explanations** – Easy-to-understand notes for each command


## Purpose
The goal of this repository is to **build confidence with Linux commands**, understand their usage, and prepare for real-world DevOps tasks.
